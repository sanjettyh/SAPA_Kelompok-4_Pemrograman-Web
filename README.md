## 📖 Deskripsi

**SAPA (Sistem Aduan dan Pendampingan Anti-Bullying)** adalah aplikasi web yang memungkinkan siswa melaporkan perundungan (*bullying*) secara **aman dan anonim**, membantu Guru BK mengelola dan memantau penanganan kasus, serta menyediakan **konseling daring** dan **edukasi anti-bullying**.

SAPA mengadaptasi pelaporan berbasis tiket dari **LAPOR!** dan konsultasi daring dari **Halodoc**, sehingga korban mendapat jalur **keadilan** (pelaporan) sekaligus **pemulihan** (pendampingan psikologis) dalam satu platform.

Proyek ini merupakan tugas kelompok mata kuliah **Pemrograman Web**, Program Studi Teknik Informatika, Universitas Teknologi Bandung.

## ❗ Masalah yang Diselesaikan

- Siswa takut melapor karena identitas pelapor tidak terjamin
- Bukti pendukung kurang sehingga kasus sulit diverifikasi
- Korban tidak dapat memantau tindak lanjut laporan
- Pendampingan psikologis belum terintegrasi dengan proses pelaporan

## ✨ Fitur Utama

- 📝 Aduan berbasis tiket dengan unggah bukti
- 🕶️ Laporan anonim (identitas disamarkan untuk Guru BK dan admin)
- 📍 Pelacakan status laporan hingga selesai
- ✅ Validasi dan penanganan kasus oleh Guru BK
- 💬 Konseling via chat teks dengan Guru BK
- 📊 Dashboard statistik untuk admin
- 📚 Modul edukasi anti-bullying (artikel, video, poster, kuis)

## 👤 Aktor

| Aktor | Peran |
|-------|-------|
| **Siswa** | Membuat laporan (terbuka/anonim), memantau status, mengikuti konseling |
| **Guru BK** | Memvalidasi aduan, menjadwalkan konseling, mencatat tindak lanjut |
| **Admin** | Mengelola pengguna, kategori, dan konten edukasi; memantau laporan |
